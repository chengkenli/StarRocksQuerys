Release Notes:


1.3(2025.06.18):

    1.修复兼容性问题。
    2.修复指针安全线程。
    3.selectid.js默认值由sr-adhoc改成了sr-default。



1.2(2025.06.17):

    1.优化配置文件的读取方式，新增检测第一次运行没发现元数据表时，自动创建并插入模拟数据。
    2.增加channel对元数据库进行初始化。
    3.优化查询队列样式。
    4.新增批量查杀用户Disconnect。
    5.IP配置表由ops_starrocks_ip_system调整为cn_asset_information。

1.0(2025.05.28):

    1.前端是html+js web可视化。
    2.后端是golang gin,gorm。
    3.支持获取集群所有正在运行的语句。
    4.支持获取查询队列大查询。
    5.支持汇报查询记录。（该选项需要配置慢查询查杀）
    6.支持web使用token访问，接口使用admin二次认证，非管理员访问限制。
    7.支持多集群查询查看，查杀，批量暴力清场，释放睡眠连接。





一、访问web

需要专属token才可访问，token配置在配置文件中。
token约束:<token>+<日期>，例如配置的token是123456，那么今天是20250606，那么真正的在页面填写的时候，是1234560606。

三、查询监控

COUNT:601，RUN:7，PEND:0，SLEEP:594

分别代表，

COUNT：当前集群3个fe，共在有多少个连接。

RUN：当前正在运行的语句。

PEND：如果看起了查询队列，会有等待的状态。

SLEEP：代表挂起但未释放的连接。
